## External tools and models (not part of Sprite8)

Sprite8 talks to image models only over HTTP. Tools and model weights you connect are separate
programs with their own licences; Sprite8 does not include, download or redistribute them.

| Tool | Licence (check the project for the current terms) |
| --- | --- |
| ComfyUI | GPL-3.0 |
| ComfyUI_IPAdapter_plus (custom nodes for the IP-Adapter workflow) | GPL-3.0 |
| AUTOMATIC1111 Stable Diffusion WebUI | AGPL-3.0 |
| Hugging Face diffusers (used by the optional Python example) | Apache-2.0 |

Model weights are licensed individually — some forbid commercial use or certain applications.
Always read the model card before using a model for your game. Notes on common model families:
[models/README.md](../models/README.md).

Images you generate are subject to the licence of the model that produced them and to the laws of
your jurisdiction; Sprite8 adds no restrictions of its own.
